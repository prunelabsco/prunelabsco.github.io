Context, checks, cleanup.

## 1. Laravel Boost: context

An official MCP server. It gives your agent tools to read your app's structure, database and routes, plus a documentation API for the Laravel ecosystem. When the video was made, the Laravel docs listed over 15 tools and over 17,000 pieces of documentation.

- Repo: [laravel/boost](https://github.com/laravel/boost)

## 2. Larastan: checks

Static analysis for Laravel. It catches the bugs AI loves to write before you even run the code.

- Repo: [larastan/larastan](https://github.com/larastan/larastan)

## 3. Pint: cleanup

Laravel's own code style fixer. AI code in, clean code out.

- Repo: [laravel/pint](https://github.com/laravel/pint)
- Want it to run on its own after every AI edit? See [the auto-format hook](/a/claude-code-hooks-auto-format/).

## If you install just one

Start with **Boost**. Context is the step the other two can't fix.

Install steps change between versions, so follow each repo's README.

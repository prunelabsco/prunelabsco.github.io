When you say "make it look good", the agent guesses. And it guesses the same thing everyone else gets.

## Write one file first

`DESIGN.md`, with:

- your colors
- your fonts
- your spacing
- the things you never want to see

Then every prompt points to it. Same agent, but now it designs like it knows your brand.

## Let a skill write it

[impeccable](https://github.com/pbakaus/impeccable) can write that file for you: `teach` asks about your design and writes it, `document` builds it from the code you already have. More on impeccable: [this repo stops AI from designing ugly UIs](/a/impeccable-stops-ugly-ai-ui/).

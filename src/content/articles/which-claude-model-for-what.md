I don't use the best model for everything. Two models do almost all my work.

| Model | What it gets |
|---|---|
| Opus 5.5 | Planning: the hard thinking, the long discussions, figuring out what to build |
| Sonnet 5.5 | Building: once the plan is clear, it just runs it |

## My rule

Opus plans, Sonnet builds.

## So

- Not sure what to build yet? Start with Opus.
- Plan already clear? Hand it to Sonnet.

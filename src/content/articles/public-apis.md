- Repo: [public-apis/public-apis](https://github.com/public-apis/public-apis)

Over 500K stars on GitHub (as of Nov 25, 2026), MIT licensed.

## What's in it

- 2,398 APIs in around 50 categories
- 1,155 of them need no key at all
- a new MCP Servers section with 167 entries your agent can call directly

Every entry lists **Auth**, **HTTPS** and **CORS**. That's what makes it useful for an agent: it can filter before it writes a line.

## A prompt to try

Paste the repo link into Claude Code and ask for an API that fits your idea:

```text
https://github.com/public-apis/public-apis
Find a free API with no key for my idea: <your idea>
```

This is an example prompt, not something I ran.

## My take

The no-key filter is the real value. Just check the API is still alive before you build on it, and skip the ads at the top of the README.

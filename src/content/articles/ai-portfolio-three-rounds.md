## Round one: three setups, one brief

The brief: build my portfolio page. All three came back clean, and all three looked like every other AI site.

- **A:** my usual skill stack
- **B:** A plus [impeccable](https://github.com/pbakaus/impeccable)
- **C:** impeccable plus [Emil Kowalski's design skills](https://github.com/emilkowalski/skills), which [Prism](/prism/) found for me

Not one used an animation library. A plugin I use to keep code lean was refusing to add them. I picked C because of one small thing: a yellow highlighter behind "available for work".

## Round two: one signature motif

That highlighter became the whole page. GSAP for motion, and one three.js piece: my 861 API endpoints, as a grid the highlighter sweeps across.

## Round three: real data

More of my real numbers became objects. Not decoration, actual data.

## What I kept

What mattered wasn't which skills were installed. It was one signature motif, and my own data on screen. So I wrote that down as a taste file, a skill every design job reads first.

Picking C was my taste, on one page. Not a benchmark.
